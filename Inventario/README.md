# Inventory Management System

Sistema de inventario desarrollado en Java + Swing + MySQL.

## Tecnologías usadas

- Java
- Swing
- MySQL
- JDBC

## Funcionalidades

- Agregar productos
- Listar productos
- Actualizar productos
- Eliminar productos

## Arquitectura

- DAO
- Modelo Vista

## Base de datos

El script SQL está en:

BD/inventario.sql
